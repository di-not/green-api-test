Склонировать репозиторий.
Открыть папку проекта в терминале.
Установить зависимости: `npm ci`.
Запустить проект: `npm run dev`.
Открыть `http://localhost:3000`.

В форме указать:
-  API URL,
-  ID инстанса,
-  токен,
-  номер собеседника.
Для получения ответов включить уведомления о входящих сообщениях в настройках инстанса GREEN-API и оставить URL уведомлений пустым.
